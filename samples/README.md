# Samples

Run `backend/.venv/Scripts/python samples/generate_samples.py` (Windows) or
`backend/.venv/bin/python samples/generate_samples.py` (macOS/Linux) to draw four
synthetic demo images here. They are generated, not photographs, and are ignored by git.

Results on drawn scenes say nothing about accuracy on real photographs. To evaluate the
system, add your own images that you are allowed to use and record ground truth by hand.
